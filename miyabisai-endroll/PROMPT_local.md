# VS Code の Claude Code に渡すプロンプト

下の「ここから」〜「ここまで」をそのままコピーして、VS Code の Claude Code に貼り付けてください。
`【】` の部分は、自分の環境に合わせて書き換えてください。

---ここから---

雅祭前夜祭LIVE企画（2026/10/17）の振り返り動画に、文字を入れる作業を手伝ってください。
動画の編集（カット・音楽）は自分で済ませてあります。あなたには **文字入れだけ** をお願いします。

## 素材

- 元の動画：`【例：C:\Users\自分\Videos\miyabisai\本編.mp4】`（約3分40秒、音楽入り）
- 作業フォルダ：`【例：C:\Users\自分\Videos\miyabisai】`
- 歌詞：作業フォルダの `lyrics.txt`（自分で用意した歌詞。1行＝字幕1枚）
- クレジット：作業フォルダの `credits.txt`（下の「クレジット」の内容）
- 前に作った文字デザインの参考：GitHub の `jinshanxia74-star/sample-sites` リポジトリ、
  `claude/live-event-music-video-qdwy2z` ブランチの `miyabisai-endroll/` フォルダ
  （`make_endroll.py` がエンドロール、`make_mv.py` の `title_png()` がタイトル）。
  クローンして、デザインや処理を流用してかまいません。

**元の動画は上書きしないでください。** 出力は作業フォルダに別名で保存してください。
**元の動画の映像と音はそのまま使い、文字を重ねるだけにしてください。**

## やってほしいこと

### 1. オープニングのタイトル
- 冒頭に「雅祭前夜祭」と「LIVE 2026」を画面中央に出す（最初の約6秒、ふわっと出て消える）
- 「雅祭前夜祭」は白、「LIVE 2026」は落ち着いた金色（RGB 200,168,104）。どちらも明朝体の太め
- 背景の映像に負けないように、**ふんわりした広めの影**と、**文字のすぐ近くの薄い影**の2つを付ける
  （「LIVE 2026」が見にくかったので、特にこちらをはっきりさせたい）

### 2. メンバー紹介
- 実行委員のメンバーが映っている場面で、画面の左下に「役職　名前」のテロップを出す
- 名前と役職は `credits.txt` を使う
- **誰がどの時間に映っているかは、あなたには分からないはずなので、私に確認してください。**
  やり方の案：動画から数秒おきに画像を書き出して一覧にして見せる → 私が「0:42〜0:45 は 原口」のように答える
- 1人あたり2〜3秒、場面の切り替わりに合わせて出し入れする

### 3. 歌詞の字幕
- `lyrics.txt` の歌詞を、歌に合わせて画面下に1行ずつ出す
- 歌っているタイミングは、音声認識（Whisper など）で歌声の位置を推定して合わせてください。
  ローカルなので `pip install faster-whisper` などで入れてかまいません
- 推定したタイミングは、すぐ動画に焼き込まずに **一覧（時刻と行）にして私に見せて** ください。
  私が確認・修正してから書き出したいです
- 白文字に黒い縁取り。明朝体。エンドロール部分（最後の約1分）は、名前とかぶらないように
  左の動画の下に出す

### 4. 最後の約1分はエンドロール形式
- 曲の最後の約1分は、映像を **左側に小さく**（1920×1080 の画面で、左上から (80, 225)、大きさ 1120×630、
  細い金色の枠付き）して、**右側にクレジットを下から上へ流す**
- 切り替えるタイミングは、曲の静かになるところなど、自然な区切りを音から探して提案してください
- クレジットは右側の列の中央そろえ。役職は金色の小さめ（30px くらい）、名前は白の大きめ（48px くらい）
- 最後に「雅祭実行委員会」と「Thank you for coming!」を画面中央に出して終わる
- `make_endroll.py` のデザインをそのまま流用するのがいちばん早いと思います

## 進め方

1. まず環境を確認してください（ffmpeg、Python、Pillow、日本語の明朝体フォント）。
   足りないものは、入れ方を私に聞いてから入れてください。
   明朝体は Windows なら「游明朝」（`C:\Windows\Fonts\yumin.ttf` など）か、
   Google Fonts の「Noto Serif JP」を使ってください。
2. 元の動画の長さ・解像度・音を調べて、作業の計画（どの時間に何の文字を出すか）を一覧にして見せてください。
3. メンバー紹介と歌詞のタイミングを、私と一緒に決めてください。
4. 決まったら、**まず低画質（720p）で試しに書き出して** 確認させてください。
5. OK が出たら、元の動画と同じ画質で本番を書き出してください。

文字の位置や大きさ、出し方の細かいところは、見やすさを優先してあなたの判断で決めてかまいません。

## 事前に準備しておくもの

1. 作業フォルダを作って、自分で作った動画を入れる
2. 同じフォルダに `lyrics.txt` を作って、歌詞を1行ずつ書く（字幕1枚に出したい単位で改行）
3. 同じフォルダに `credits.txt` を作って、上の「クレジット」の中身をコピーする
4. VS Code でその作業フォルダを開いて、Claude Code を起動する
